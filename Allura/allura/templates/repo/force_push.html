By default this repository refuses any push that would discard commits. Someone attempting one sees:

remote: error: denying non-fast-forward refs/heads/master

Ticking the box above lets git push --force succeed. Be aware that:

  • Commits discarded by a force push are gone permanently unless someone still has a copy.
  • Pages for discarded commits stay visible on this site, and their entries in the activity feed cannot be removed.
  • This setting stays on until you switch it back off here.
